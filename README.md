# Interview Atlas

Мобильная платформа подготовки к техническим интервью для iOS и Android. Она объединяет учебные треки, актуализируемые вопросы, видеоразборы, практические задачи и вакансии из разрешённых источников.

## Что уже работает

- персональный экран «Сегодня» с направлением подготовки и серией занятий;
- учебные треки для Frontend, Backend, Mobile и QA;
- банк вопросов с коротким и развёрнутым ответом, тегами, датой обновления и источником;
- практические задачи с заготовкой кода, скрытым разбором и отметкой выполнения;
- живая лента вакансий Arbeitnow с серверным импортом, поиском, фильтрами и cursor pagination;
- локальный кеш вакансий, stale/error состояния, retry, pull-to-refresh и дозагрузка;
- сохранение вопросов и вакансий, локальный прогресс через Zustand + AsyncStorage;
- корректное отображение при отсутствии сети и автоматическая светлая/тёмная тема;
- deep-link-ready маршруты `/question/:id`, `/task/:id` и `/vacancy/:id`.

Боевой сбор выполняется только на backend через разрешённый публичный API. Мобильное приложение не содержит ключей, не скрейпит сайты напрямую и всегда сохраняет атрибуцию и ссылку на оригинал.

## Стек

- Expo SDK 57 + React Native + TypeScript;
- Expo Router;
- Zustand с AsyncStorage для несекретного локального прогресса;
- NetInfo для состояния сети;
- нативные back-жесты, Android ripple и haptics.
- Fastify, Zod и PostgreSQL на backend;
- Arbeitnow Public Job Board API как первый живой источник.

## Запуск

Установите зависимости приложения и backend:

```bash
npm install
npm --prefix server install
```

Запустите backend без PostgreSQL — данные будут храниться в памяти:

```bash
npm run server:dev
```

В другом терминале запустите приложение:

```bash
npm run ios
```

Для Android используйте `npm run android`, для web-preview — `npm run web`.

Для физического устройства скопируйте `.env.example` в `.env.local` и укажите LAN-адрес компьютера в `EXPO_PUBLIC_API_URL`. Android Emulator по умолчанию использует `http://10.0.2.2:4000`, iOS Simulator — `http://127.0.0.1:4000`.

Для постоянного хранилища скопируйте `server/.env.example` в `server/.env`, создайте базу и примените миграцию:

```bash
npm --prefix server run migrate
npm run server:dev
```

## Проверки

```bash
npm run typecheck
npm run lint
npm run export:web
npm run server:typecheck
npm run server:test
```

CI намеренно не добавлен: на текущем этапе приоритет у функционала.

## Архитектура данных

Контракты клиента находятся в `src/services/contracts.ts`, backend — в `server/src`. API описан в [docs/API.md](docs/API.md), поток вакансий — в [docs/VACANCY_INGESTION.md](docs/VACANCY_INGESTION.md), продуктовый план — в [docs/PRODUCT.md](docs/PRODUCT.md), этапы разработки — в [docs/ROADMAP.md](docs/ROADMAP.md).

## Ближайшие этапы

1. редакторская CMS для вопросов, задач, видео и вакансий;
2. авторизация и облачная синхронизация прогресса;
3. персональный план подготовки и уведомления;
4. рекомендации вакансий по навыкам и пробелам в подготовке;
5. продвинутая практика и видео;
6. подготовка beta-релиза.

После завершения каждого этапа обновляются roadmap и README, выполняются локальные проверки, создаётся отдельный коммит и изменения отправляются в `main`. CI на текущей функциональной стадии не используется.
